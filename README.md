# Chess Game - WIP #

Chess Game – Work In Progress ♟️

This is a work-in-progress chess game built with a focus on clean UI, smooth gameplay, and adherence to official chess rules. The project aims to support both player-vs-player and player-vs-AI modes, with future plans for move history, undo functionality, and custom board themes.

The goal is to create a fully functional, interactive chess experience that runs seamlessly across platforms. Key focuses include intuitive controls, visual feedback for legal moves, and efficient game logic.

Currently under active development — originally this was meant to be an end of year project for Object Oriented Programming course, I fell in love with it but currently shelved due to in real life time management issues.
